# WireMark

WireMark is an all-in-one, visual-first product environment. The running product is the primary IDE surface: connect GitHub, GitLab, or a local repository, review and trust its execution plan, build it, and work directly over the live canvas.

## This repository

`wiremark-web` is the public front-facing website for WireMark at [wiremark.net](https://wiremark.net).

Site content and the GitHub Pages build are scaffolded by a separate workstream. This repository is the hosting surface and the GitLab-to-GitHub mirror target.
